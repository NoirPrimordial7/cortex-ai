# Author review by section

| Section | Author verification |
|---|---|
| Title and authors | Confirm name order, institution styling and corresponding email |
| Abstract | Confirm quantitative wording and main limitation |
| Introduction | Check the integrated contribution and confirm prior project material disclosure |
| Related work | Revisit the direct temporal and access-aware search comparators and confirm reference metadata |
| Problem and RQs | Decide whether findings on partial gates and optional passage retrieval meet target venue expectations |
| Architecture and trust | Confirm expected roles, deployment boundary and scope of exposure checks |
| Method | Verify date boundaries, authority ranks, exact conflict fingerprint, citation mechanism and signer boundary |
| Implementation | Verify pinned commit and terminology for the two retrieval paths |
| Experiment | Independently label the new synthetic dataset and approve baseline definitions |
| Results | Agree which QA figures belong in the paper, then confirm all denominators and timing context |
| Discussion and limitations | Confirm reviewer dependence, single-process testing and limits on data and security claims |
| Conclusion and declarations | Approve reproducibility release and AI assistance disclosure |
| References and figures | Check citations, in-text figure references and quality at actual size |
